# Project Brief — Toggle Component

## Original Brief

Build a versatile toggle component as part of a design system. These components will be essential for forms, data entry interfaces, and other interactive elements across various projects and apps found within the platform.

### Component Properties & States

- **Sizes:** Small and medium
- **States:** Initial/default, hover, focus, and disabled

### Implementation Requirements

- **Design fidelity:** Follow the design as closely as possible — text color, font size, font weight, spacing, dimensions
- **Toggling:** Clicking the toggle should switch between active and inactive states
- **Cross-browser compatibility:** Chrome, Firefox, and Safari
- [Stretch] **Performance optimization:** Optimize assets and code for quick load times
- [Stretch] **Accessibility and semantics:** Semantic HTML, ARIA roles, proper alt tags

## Implementation Checklist

- [ ] Two sizes: small and medium
- [ ] Off state (default) — gray track, thumb on left
- [ ] On state — indigo track, thumb on right
- [ ] Hover state — visual feedback on hover
- [ ] Focus state — visible focus ring for keyboard users
- [ ] Disabled state — reduced opacity or muted color, not clickable
- [ ] Toggle switches between on/off on click
- [ ] Works in Chrome, Firefox, and Safari
- [ ] [Stretch] Accessible: uses `<button>` or `<input type="checkbox">` with ARIA attributes
- [ ] [Stretch] Keyboard operable (Space/Enter to toggle)
